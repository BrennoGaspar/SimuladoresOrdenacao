# Simulador de Algoritmos de Ordenação

> Visualização gráfica e interativa da execução de algoritmos de ordenação em tempo real utilizando Java e a biblioteca JSGE.

## 🎯 Objetivo
Representar graficamente a execução passo a passo dos principais algoritmos de ordenação, facilitando o aprendizado visual de suas mecânicas e diferenças de desempenho.

## 📊 Algoritmos
#### Quadráticos $O(n^2)$:
- Bubble Sort
- Insertion Sort
- Quick Sort
- Selection Sort
- Shell Sort

#### Linear Logarítmico $O(n. \log n)$:
- Merge Sort
- Heap Sort

## 🛠️ Principais Funcionalidades
- Menu para escolha do algoritmo a ser executado
- Janela com input para a quantidade de elementos (10 a 50)
- Menu lateral para melhor orientação ao usuário
- Slider para controle de velocidade (0.1x até 10x)
- **Exclusivo para o Heap Sort** -> Desenho da árvore binária sendo ordenada, para melhor compreensão do algoritmo em questão.

## ⚙️ Ferramentas Utilizadas
- **IDE:** Netbeans
- **Linguagem:** Java
- **Biblioteca:** JSGE e Swing
